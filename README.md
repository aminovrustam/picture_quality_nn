# Сравнение изображений

Модель предсказывает, какое из двух изображений (`image_1` или `image_2`) лучше (`is_image1_better = 1` или 0). 

## Этапы

- **Предобработка**  
  Изображения конвертируются в RGB, ресайзятся до 128×128 и нормализуются.

- **Архитектура**  
  - **FeatureExtractor** – свёрточная сеть:  
    - 3 блока `ConvBlock` (с понижением разрешения и skip‑соединениями)  
    - глобальный пулинг → выход 256 признаков  
  - **ComparisonHead** – принимает признаки двух изображений, конкатенирует их вместе с модулем разности и поэлементным произведением (`[f1, f2, |f1-f2|, f1*f2]`), затем два полносвязных слоя (256→256→1).  
  - Выход – логит (BCEWithLogitsLoss).

- **Постобработка**  
  Подбор оптимального порога по F1‑мере и критерию Юдена (Youden's J) на валидации.
